# Лабораторная работа №7
## Тема: 
Асинхронная обработка данных через очереди сообщений (RabbitMQ / Kafka)


## Цель
 Научиться работать с очередями сообщений и реализовывать асинхронную обработку данных в PHP.
Познакомиться с интеграцией брокеров сообщений RabbitMQ и Apache Kafka через Docker.
Научиться создавать producers (отправители) и consumers (обработчики) задач.



## Содержимое проекта
- `docker-compose.yml` — конфигурация Docker Compose (php-fpm + nginx)
- `Dockerfile` — конфигурация PHP-FPM 
nginx.conf — конфигурация Nginx

- `www/index.php` — главная страница системы управления библиотекой

- `www/QueueManager.php` — класс для работы с файловой очередью сообщений

- `www/Student.php` — класс для работы с данными студентов и заявок

- `www/fileDB.php` — класс для работы с файловой БД (JSON)

- `www/send.php` — обработчик отправки заявок в очередь

- `www/worker.php` — воркер для обработки сообщений из очереди
